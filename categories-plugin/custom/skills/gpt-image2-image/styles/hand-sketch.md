# 手绘草图 / Hand Sketch

## 风格ID
hand-sketch

## 风格名称
手绘草图 / Hand Sketch

## 风格描述
白板手绘与工作坊视觉：轻松、解释性强、富有人味，适合表达过程和想法。

## 基础视觉提示词
请使用高质量手绘草图 / sketchnote 风格。

- 保持手绘线条感、注释感、白板思维和过程表达
- 可以使用少量强调色帮助分组，但整体仍以手绘为主
- 强调可理解性、亲和力和讲解感，不要太凌乱
- 画面应有构思过程、可视化思考和 workshop 气质
- 避免低幼简笔画、脏乱草稿和过度写实

## 适用场景
工作坊、产品脑暴、培训插图、方法论讲解图
