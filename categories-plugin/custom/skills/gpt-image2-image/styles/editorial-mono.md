# 编辑黑白 / Editorial Mono

## 风格ID
editorial-mono

## 风格名称
编辑黑白 / Editorial Mono

## 风格描述
Kinfolk / Monocle 风格的编辑视觉：克制、留白、高级、偏杂志封面气质。

## 基础视觉提示词
请使用高级编辑设计与杂志视觉语言。

- 以黑、白、灰为主，可加入极少量低饱和强调色
- 强调留白、秩序、网格感、摄影感或静物感
- 整体气质安静、成熟、克制、具有出版物美感
- 细节需精致，避免信息拥挤和社交媒体模板感
- 避免廉价时尚海报、过度装饰和粗暴对比

## 适用场景
品牌发布、杂志封面、文化内容头图、生活方式视觉
