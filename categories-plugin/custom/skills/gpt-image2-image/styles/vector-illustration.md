# 复古矢量插画 / Vector Illustration

## 风格ID
vector-illustration

## 风格名称
复古矢量插画 / Vector Illustration

## 风格描述
复古平面插画与现代信息设计结合：轮廓清晰、色块干净、友好但不幼稚。

## 基础视觉提示词
请使用高质量矢量插画风格，强调清晰轮廓和干净色块。

- 采用简洁几何造型、有限色盘、可读性强的角色或物体设计
- 可以带轻微复古印刷感，但整体仍要现代、清爽、易懂
- 强调黑色描边、统一形状语言、平衡构图和高辨识度
- 避免写实、3D、复杂光影和廉价儿童插画感

## 适用场景
教育培训、品牌故事、科普配图、社区宣传图
