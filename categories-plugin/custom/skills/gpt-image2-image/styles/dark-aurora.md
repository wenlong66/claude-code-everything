# 深色霓虹 / Dark Aurora

## 风格ID
dark-aurora

## 风格名称
深色霓虹 / Dark Aurora

## 风格描述
对标 Linear / Vercel / Cursor / Arc Browser 的高级深色视觉：深空底、极光弧光、半透明玻璃、克制的科技感。

## 基础视觉提示词
你是一位顶级数字视觉设计师。请使用高级、克制、现代的深色科技美学。

- 背景以深空黑和冷色渐变为主，避免纯黑死板背景
- 使用紫、青、粉中的 1-2 种作为极光高光色，但保持克制
- 可以出现半透明玻璃材质、柔和光晕、细线几何和少量星尘点缀
- 强调整体完成度、高级感、未来感与留白
- 避免廉价赛博朋克、过度噪点、过饱和荧光和杂乱元素

## 适用场景
AI 产品、开发者工具、SaaS 官网视觉、技术活动海报、未来感 KV
