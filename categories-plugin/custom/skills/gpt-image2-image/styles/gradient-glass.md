# 空间玻璃 / Gradient Glass

## 风格ID
gradient-glass

## 风格名称
空间玻璃 / Gradient Glass

## 风格描述
Apple Vision Pro / Spatial Computing 气质：通透玻璃、柔和渐变、空气感、未来但不冰冷。

## 基础视觉提示词
请使用高级、通透、具有空间感的玻璃拟态视觉。

- 以浅色或中性色背景叠加柔和渐变光晕
- 使用半透明玻璃卡片、磨砂材质、柔和反射与折射感
- 色彩以蓝、青、紫、白为主，氛围干净、现代、发光但不刺眼
- 强调轻盈、通透、空间深度与精致高光
- 避免厚重阴影、脏污纹理、低端 UI 感和复杂噪声
