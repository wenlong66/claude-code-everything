# 日式侘寂 / Japanese Wabi

## 风格ID
japanese-wabi

## 风格名称
日式侘寂 / Japanese Wabi

## 风格描述
无印良品 / 原研哉系侘寂美学：克制、静谧、留白、天然材质、低饱和。

## 基础视觉提示词
请使用日式侘寂与现代极简结合的高级视觉语言。

- 使用米白、砂色、木色、灰褐、墨色等低饱和天然色盘
- 强调留白、平静、呼吸感、天然材质与细腻纹理
- 可以出现纸张、陶土、木材、布料、石材等自然触感
- 整体需要高级、安静、有文化气息，不要商业化过强
- 避免鲜艳颜色、强烈对比、复杂装饰和俗气东方元素堆砌

## 适用场景
生活方式品牌、文化讲座、茶道主题、奢侈品静物、展览视觉
