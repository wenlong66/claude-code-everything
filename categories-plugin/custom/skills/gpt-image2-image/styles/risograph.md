# Riso 印刷 / Risograph

## 风格ID
risograph

## 风格名称
Riso 印刷 / Risograph

## 风格描述
双套色印刷、网点纹理、实验海报气质：独立、创意、年轻、带手工感。

## 基础视觉提示词
请使用高质量 risograph / 独立印刷海报风格。

- 使用有限的 2-3 色配色方案，并带有明显层次关系
- 允许出现网点、轻微错位、纸张颗粒和印刷不完美感
- 整体应有实验性、艺术性和高辨识度
- 强调构图张力和海报视觉冲击，但不要脏乱
- 避免纯数字光滑质感和廉价复古滤镜

## 适用场景
创意活动海报、工作室宣传图、艺术项目视觉、年轻品牌内容
