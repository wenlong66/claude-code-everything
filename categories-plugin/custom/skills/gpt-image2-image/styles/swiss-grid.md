# 瑞士网格 / Swiss Grid

## 风格ID
swiss-grid

## 风格名称
瑞士网格 / Swiss Grid

## 风格描述
Bauhaus / Swiss International Style：理性、秩序、几何、网格、现代主义。

## 基础视觉提示词
请使用瑞士国际主义网格风格，强调秩序、字体感和几何构成。

- 采用清晰网格、强结构感、精准对齐和大面积留白
- 色彩简洁，可用红、黑、白、灰或少量主色强调
- 强调现代主义海报语言、理性美感和信息设计感
- 允许几何图形、无衬线字体感、版式张力和极简构图
- 避免装饰主义、手账感和流行社媒海报套路

## 适用场景
学术海报、展览视觉、严肃发布、博物馆与机构内容配图
