# 清爽科技蓝 / Clean Tech Blue

## 风格ID
clean-tech-blue

## 风格名称
清爽科技蓝 / Clean Tech Blue

## 风格描述
Stripe / Linear 式蓝白科技商务视觉：专业、清晰、克制、可信赖。

## 基础视觉提示词
请使用高完成度的蓝白科技商务美学。

- 主色调以白、浅灰、深蓝、亮蓝为主
- 画面结构清晰，强调秩序感、专业感和现代感
- 可以使用轻量图形、干净留白、几何构图和简洁数据感元素
- 整体要像顶级科技公司官网或融资材料视觉
- 避免卡通感、花哨质感、杂色背景和廉价商务模板风

## 适用场景
商业计划书配图、融资路演视觉、企业官网头图、专业海报
