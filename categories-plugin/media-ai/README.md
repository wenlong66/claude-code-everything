# Media AI 分类说明

该目录提供媒体内容生成与处理相关能力，面向图文、视频等创作与生产场景。

## 当前目录功能

- **内容生成**：支持多模态内容创作与增强。
- **视频相关工作流**：支持视频编辑与处理类能力。
- **媒体工具整合**：将媒体 AI 工具能力封装为可复用技能。
